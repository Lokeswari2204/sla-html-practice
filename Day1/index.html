HTML Page

About HTML

HTML stands for HyperText Markup Language.

HTML is used to create web pages.

HTML gives structure to a web page.

History of HTML

HTML was created by Tim Berners-Lee in 1991.

HTML5 became a standard in 2014.

HTML Document Structure

DOCTYPE tells the browser that the document is HTML5.

HTML is the root element of the page.

Head contains information about the page.

Body contains the visible content of the page.

Root Element

The html element is the root element of an HTML page.

It contains the head and body of the document.

Container Elements

The div element is used to group content.

The section element is used to group related content.
